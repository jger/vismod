# VisMod for JavaScript / TypeScript & React

> Status: Planned (skeleton for `v0.0.1`)

## Planned Packages

- **`@vismod/core`** — Load, validate (`spec/schema/vismod.v1.schema.json`), and execute `*.vismod.yaml` flows bound to modular TypeScript/JavaScript handlers, with optional execution trace emission.
- **`@vismod/react`** — Embeddable `<VisModViewer flow={...} role={...} />` React component that renders live interactive flowcharts inside your app, respecting `visibility` (`public`, `admin`, `internal`).
